Cue 0.3.0

  • Native Sparkle updates on macOS, with automatic checks and Check for Updates in the Cue menu bar menu.
  • Explicit Codex model and reasoning effort selection using your signed-in account.
  • Improved microphone echo cancellation with an updated Electron runtime.
  • Local transcription improvements, a redesigned overlay, global recovery shortcuts, and streamed answer sizing.

Requires macOS 13 or later. Native Core ML transcription requires Apple Silicon and macOS 14 or later; local model files are downloaded separately. Intel Macs can use other configured transcription providers.

This is the first release with an updater. Install it manually once; subsequent releases will be offered in Cue.
