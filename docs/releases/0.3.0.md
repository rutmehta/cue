Cue 0.3.0 brings the recent overlay, audio, transcription, and Codex improvements into a signed macOS release.

- Native Sparkle updates, automatic update checks, and **Check for Updates…** in Cue's menu bar menu.
- Explicit Codex model and reasoning effort selection using your ChatGPT account.
- Updated Electron runtime and improved microphone echo cancellation.
- Improved local transcription, overlay readability and sizing, and global recovery shortcuts.

Download the **arm64** ZIP for Apple Silicon or **x64** ZIP for Intel. Unzip and move **Cue.app** into **Applications**. This first updater-enabled release needs one manual install; future releases will be offered in Cue.

Requires macOS 13+. Native Core ML transcription requires Apple Silicon and macOS 14+, and downloads model files separately. Intel users can configure other transcription providers.

Both apps are Developer ID signed and Apple notarized. SHA256SUMS provides archive checksums; appcast.xml is the signed Sparkle update feed.
