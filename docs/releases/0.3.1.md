Cue 0.3.1 ships active-chat context and the capture, history-scrolling, and overlay fixes made since 0.3.0.

- Follow-ups include completed questions and answers from the active chat, across feature modes. **New Chat** clears context; failed and late replies stay out of the new chat.
- Earlier answers remain scrollable in compact mode.
- Hidden Cue releases action shortcuts, keeping only the show/hide shortcut active. Explicit move and side resize handles improve positioning.
- Capture failures have clearer permission guidance, and recovered transcription warnings clear automatically.

Chat context is in memory, bounded to 12 completed exchanges and 64,000 characters. It does not persist across app restarts, and previous screenshots are not included in follow-up requests.

**Cue 0.3.0 users:** choose **Check for Updates…** from Cue's menu-bar icon menu, or accept the automatic update offer.

**New installations:** download **arm64** for Apple Silicon or **x64** for Intel, unzip, and move Cue.app to Applications. Requires macOS 13+. Native Core ML transcription requires Apple Silicon and macOS 14+ and downloads model files separately.

Both Mac builds are Developer ID signed and Apple notarized. The signed appcast and SHA256SUMS accompany the downloads.
