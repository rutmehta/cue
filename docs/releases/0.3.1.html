Cue 0.3.1

  • Follow-up questions now include earlier completed questions and answers from the active chat, across feature modes. New Chat clears this context, and failed or late replies cannot repopulate it.
  • Earlier answers remain scrollable in compact mode.
  • When Cue is hidden, only the show/hide shortcut remains active. Explicit move and left/right resize handles make overlay positioning easier.
  • Clearer screen-capture permission errors and automatic clearing of recovered transcription warnings.

Chat context is kept in memory for the current chat, bounded to 12 completed exchanges and 64,000 characters. Previous screenshots are not retained as follow-up images.

Requires macOS 13 or later. Native Core ML transcription requires Apple Silicon and macOS 14 or later; local models are downloaded separately.
